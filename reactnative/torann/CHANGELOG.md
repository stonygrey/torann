## 0.3.0

* First release of the React Native package. TypeScript API, as an Expo module, over the
  Swift implementation on iOS (CryptoKit, 25519, ChaChaPoly, AESGCM, SHA256, SHA512) and
  the Kotlin implementation on Android (JCA and Bouncy Castle, adding 448, BLAKE2s, and
  BLAKE2b). The version matches the C#, Swift, Kotlin, and Flutter packages released
  from the same repository tag.
